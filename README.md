# lone_star_frontier
Wild West Texas Ranger RPG with RuneScape-style skill progression and AI NPCs.

v2.0 specs on `main` are the source of truth:

- `PRD.md` — product rules
- `SCHEMA.md` — tables, seed numbers, and tool contracts
- `STYLE_GUIDE.md` — layout, components, and visual tokens
- `EVALS.md` — v2.2 backend eval gate, after v2.0. Not built in this pass.
- `CONTEXT.md` — how Lovable, Replit, and this repo split the work
- `AGENTS.md` — what each tool is allowed to edit
- `src/PROTOTYPE_DRIFT.md` — Lovable's list of prototype rules the specs do not state yet
